# Recovery Day Heir Drill Packet Template

This template helps an owner prepare a practice packet for an heir or trusted
helper. The packet must use disposable test-wallet material only. It must not
contain the owner's real descriptor, seed words, passphrase, private keys, PSBTs,
transaction hex, or wallet password.

The desktop app can generate a drill packet with:

- `manifest.json`
- `README-heir-drill.md`
- `wallet/practice-wallet.json`

Use the outline below when printing a companion cover sheet or reviewing the
generated packet before handing it to an heir.

## Cover Sheet

```text
Bitcoin Lifeboat Heir Drill Packet

Packet ID:
Prepared by:
Prepared for:
Date prepared:
Practice network: regtest or Signet

This packet is for a drill only.
It contains no real owner wallet material.
Do not send seed words, passphrases, wallet passwords, or private keys to anyone.
Bitcoin Lifeboat will never contact you.
```

## Packet Checklist

- [ ] `manifest.json` says `contains_real_user_material=false`.
- [ ] `manifest.json` says `includes_disposable_private_material=true`.
- [ ] `README-heir-drill.md` explains the practice steps in plain language.
- [ ] `wallet/practice-wallet.json` is for regtest or Signet only.
- [ ] The heir knows this is a rehearsal, not a real emergency.
- [ ] The owner has recorded when the drill should be repeated.

## Manifest Template

```json
{
  "packet_type": "bitcoin-lifeboat-heir-drill",
  "packet_id": "<uuid generated by the app>",
  "network": "regtest",
  "contains_real_user_material": false,
  "includes_disposable_private_material": true,
  "files": [
    "manifest.json",
    "README-heir-drill.md",
    "wallet/practice-wallet.json"
  ]
}
```

## Heir Confidence Check

Ask the heir to answer these out loud after the walkthrough:

- I know this packet is practice material.
- I know Bitcoin Lifeboat will never contact me.
- I know where the real written instructions are stored.
- I know who I would call before taking action in a real emergency.
- I know not to type seed words into a website, chat, email, or support form.

If the heir cannot answer one of these, revise the owner's real runbook before
the next drill.

## Owner Follow-Up

After the drill:

1. Save the public-safe family drill receipt.
2. Write down what confused the heir.
3. Update the real runbook privately.
4. Schedule the next practice date.
5. Destroy or archive the disposable packet according to your own practice
   policy.
